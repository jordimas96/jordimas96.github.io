The project

The official website uses infinite scrolling that makes it difficult to access older episodes. In addition, the RSS feed only retains the 350 most recent episodes.
To solve this, I created an application that indexes all available episodes and organizes them by season and type, making it much faster to find and download episodes.
To obtain the data, I developed scripts with Playwright that scrape the official website and generate a JSON file containing episode information, including the title, season, description, and MP3 link.
Later, I used the public 3Cat API to supplement this information with additional data, such as images and the duration of each episode.

Features

  • Browse all episodes, organized by season and type (regular, special, and best moments)
  • Flexible episode search that allows searching by any criteria
  • Download individual episodes
  • Download multiple episodes at once
  • Preview of the total size and estimated download time
  • Progress bar showing the remaining time
  • Parallel download management to avoid overloading the server
  • Automatic tracking of viewed episodes, also visible in the multi-selection bar
  • Backup of viewed episodes through export and import, making it easier to switch devices

Technologies

  • Angular, HTML, TypeScript, CSS
  • JSON files as a database for episode data
  • Playwright (scraping scripts)

  • GitHub repository
  • Official show (3Cat)

El proyecto

La web oficial utiliza un sistema de scroll infinito que dificulta el acceso a los episodios antiguos. Además, el feed RSS solo conserva los 350 episodios más recientes.
Para solucionarlo, creé una aplicación que indexa todos los episodios disponibles y los organiza por temporada y tipo, permitiendo localizarlos y descargarlos de manera mucho más rápida.

The project

The official website uses infinite scrolling that makes it difficult to access older episodes. In addition, the RSS feed only retains the 350 most recent episodes.
To solve this, I created an application that indexes all available episodes and organizes them by season and type, making it much faster to find and download episodes.
To obtain the data, I developed scripts with Playwright that scrape the official website and generate a JSON file containing episode information, including the title, season, description, and MP3 link.
Later, I used the public 3Cat API to supplement this information with additional data, such as images and the duration of each episode. }
